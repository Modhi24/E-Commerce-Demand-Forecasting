# E-Commerce Demand Forecasting Using Machine Learning

## Project Overview
This project explores e-commerce sales data from a Zid case study to analyze sales patterns and forecast product demand using machine learning.

The project aims to support data-driven decision-making and improve inventory planning.

## Project Objectives
- Analyze e-commerce sales data.
- Identify sales trends and patterns.
- Prepare and preprocess data for machine learning.
- Build a Random Forest model for demand forecasting.
- Evaluate forecasting performance using Mean Absolute Error (MAE).
- Provide insights to support inventory management.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Model
**Random Forest**

The model is used to predict product demand based on historical sales data.

## Dataset
The project uses Orders, Products, and Calendar datasets from the Zid case study.

**Note:** The original datasets are not included in this repository. They are required to reproduce the analysis and run the notebook.

## Project Files
- `Zid_case_study_SOLVED.ipynb` — Data analysis, preprocessing, machine learning, and forecasting.

## Project Context
Developed as part of an e-commerce data analytics case study involving Zid.
